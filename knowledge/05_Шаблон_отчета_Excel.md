# Шаблон Excel-отчёта

Итоговый файл должен содержать листы:

## 1. Сводка

| Показатель | Значение |
|---|---|
| Дата проверки | |
| Всего договоров | |
| Уникальных ИНН | |
| Найдено в реестре | |
| Не найдено | |
| Право приостановлено | |
| Превышение ВВ | |
| Превышение ОДО | |
| Критичные | |
| Ручная проверка | |
| Норма | |
| Сумма, принятая СРО к учёту | |
| Остаток ОДО (расчёт) | |

## 2. Проверка компаний

Колонки:
- ИНН
- Компания
- Найдена в реестре (да/нет)
- Состояние права
- Уровень ВВ (текст)
- Лимит ВВ (руб.)
- Макс. один договор (руб.)
- Проверка ВВ (ок / превышение)
- Уровень ОДО (текст)
- Лимит ОДО (руб.)
- Остаток ОДО по договорам (руб.)
- Расчёт обязательств из реестра (руб.)
- Проверка ОДО (ок / превышение / не требуется / нет ОДО)
- Кол-во договоров
- Кол-во конкурентных
- Итоговый риск
- Комментарий

## 3. Договоры с расчётом

Колонки:
- ИНН
- Компания
- Номер договора
- Дата
- Стоимость к учёту
- Исполнено
- Остаток
- Способ закупки
- Конкурентный (да/нет/неясно)
- Участвует в ОДО (да/нет)
- Комментарий

## 4. Риски

Только строки со статусом **КРИТИЧНО**.

## 5. Ручная проверка

Только строки со статусом **РУЧНАЯ ПРОВЕРКА**.
