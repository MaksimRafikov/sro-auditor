## 2. Проверка компаний

Колонки:
- ИНН
- Компания
- Найдена в реестре (да/нет)
- Состояние права
- Уровень ВВ (текст)
- Лимит ВВ, ₽
- Макс. один договор, ₽
- Проверка ВВ (ок / превышение)
- Уровень ОДО (текст)
- Лимит ОДО, ₽
- Остаток ОДО по договорам, ₽
- Расчёт обязательств из реестра, ₽
- Дата расчёта обязательств
- Остаток ОДО на дату расчёта, ₽
- Проверка ОДО (ок / превышение / не требуется / нет ОДО)
- Кол-во договоров
- Кол-во конкурентных
- Договоров в периоде приостановки
- Макс. договор в приостановке, ₽
- ВВ в приостановке (ок / превышение / н/д)
- Остаток ОДО в приостановке, ₽
- ОДО в приостановке (ок / превышение / н/д)
- Дата регистрации в реестре
- Договоров до регистрации
- Итоговый риск
- Комментарий

Оформление: автофильтр, закреплённая шапка, подсветка строк по риску (красный / жёлтый / зелёный штамп в колонке риска), суммы числом.

## 3. Договоры с расчётом

Колонки:
- ИНН, Компания, Номер, Дата
- Стоимость к учёту / Исполнено / Остаток
- Способ закупки, Тип (44/223/615/прямой/…)
- Конкурентный, Участвует в ОДО
- Исключён из обязательств
- До регистрации в реестре (да — на дату заключения членства нет, в ВВ/ОДО не входит)
- В периоде приостановки
- Комментарий

## 4. К исполнению

Очередь оператора: только **КРИТИЧНО**, сортировка по тяжести
(приостановка/право → превышение ВВ/ОДО → нет в реестре) и сумме.

Колонки:
- ИНН
- Компания
- Тип риска (кратко)
- Макс. один договор, ₽
- Остаток ОДО, ₽
- Что проверить
- Черновик для письма / протокола

## 5. Риски

Только строки со статусом **КРИТИЧНО** (те же колонки, что «Проверка компаний»).

## 6. ЕРЧ

Только строки со статусом **РУЧНАЯ ПРОВЕРКА** и флагом сверки ЕРЧ
(расхождение остатка ОДО с «Расчётом обязательств»).

## 7. Данные неполные

Только строки со статусом **РУЧНАЯ ПРОВЕРКА** и дырами в данных:
нет способа закупки, странный формат суммы, нет колонки исполнения и т.п.
Компания с обоими факторами попадает на оба листа.
