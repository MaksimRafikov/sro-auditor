# Методика проверки СРО: ВВ и ОДО

## Цель

Проверить, может ли член строительной СРО выполнять работы по договорам в пределах своего уровня ответственности по компенсационным фондам.

## Два фонда — две разные проверки

### КФ ВВ (компенсационный фонд возмещения вреда)

- Обязателен для всех членов строительной СРО.
- Связан с ответственностью за вред из‑за недостатков работ.
- Ограничивает **максимальную стоимость одного договора**.

### КФ ОДО (компенсационный фонд обеспечения договорных обязательств)

- Нужен тем, кто заключает договоры **конкурентным способом** (торги, конкурсы, аукционы, закупки).
- Ограничивает **совокупный объём обязательств** по всем таким договорам одновременно.
- Количество договоров не ограничено — ограничена сумма.

## Базовые правила

1. Сначала проверяем **состояние права** (действует / приостановлено).
2. Затем сравниваем **максимальный один договор** с уровнем **ВВ**.
3. Для конкурентных договоров считаем **остаток обязательств** и сравниваем с уровнем **ОДО**.
4. Если данных не хватает или есть противоречия — статус «ручная проверка», а не уверенный вывод.

## Формула остатка ОДО по договору

```text
Остаток = Стоимость, принятая СРО к учёту − Стоимость принятых/исполненных работ
```

Если колонки исполнения нет — используем полную стоимость и явно фиксируем допущение.

## Что считать конкурентным договором

Явно конкурентные признаки:
- 44-ФЗ
- 223-ФЗ
- 615-ПП
- конкурс / аукцион / тендер / закупка
- заполненный признак договора ОДО в выгрузке

Если способ закупки не указан — договор помечается как «требует ручной проверки».

## Практическая формула для одной компании

1. Самый крупный один договор → уровень **ВВ**.
2. Есть ли конкурентные договоры → нужен ли **ОДО**.
3. Сумма остатков по конкурентным договорам → уровень **ОДО**.
4. При превышении — доплата до следующего уровня.
