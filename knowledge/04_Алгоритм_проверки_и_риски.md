# Алгоритм проверки и классификация рисков

## Пошаговый алгоритм

1. Прочитать реестр членов СРО и реестр договоров.
2. Определить колонки по словарю (см. `03_Словарь_колонок_и_нормализация.md`).
3. Нормализовать ИНН в обоих файлах.
4. Сгруппировать договоры по ИНН.
5. Для каждого ИНН из договоров (и при необходимости из реестра):
   - найти карточку в реестре СРО;
   - проверить состояние права;
   - собрать все периоды приостановки (пара дат и/или текст «Периоды приостановок» с несколькими интервалами через «;»);
   - отобрать договоры, у которых дата заключения попадает в любой из этих периодов;
   - найти max одного договора по договорам с даты регистрации в реестре (если дата есть) и отдельно max только внутри периодов приостановки;
   - сравнить оба max с лимитом ВВ;
   - отобрать конкурентные договоры с той же даты и отдельно конкурентные внутри периодов приостановки;
   - посчитать остаток ОДО = сумма (принято − исполнено) по каждой из этих групп;
   - сравнить оба остатка с лимитом ОДО;
   - если уровня ОДО нет, а есть договоры 44-ФЗ / 223-ФЗ / 615-ПП с даты регистрации — отдельный риск;
   - договоры с датой заключения раньше регистрации в реестре в лимиты не входят; в отчёте они остаются с пометкой, что на дату заключения членства нет;
   - сравнить свой расчёт остатка ОДО с колонкой «Расчёт обязательств» реестра (сверка ЕРЧ, если колонка есть);
   - присвоить итоговый риск.
6. Сформировать сводку по нумерованному перечню, список критичных, ручную проверку, детальную таблицу.

## Нумерованный перечень сводки

Одна компания может попасть в несколько пунктов сразу.

1. **Нет уровня ОДО** — лимит ОДО пуст, и есть хотя бы один договор 44-ФЗ, 223-ФЗ или 615-ПП.
2. **Превышен уровень ВВ** — максимальный договор с даты регистрации в реестре больше лимита ВВ.
3. **Превышен уровень ОДО** — остаток по конкурентным договорам с даты регистрации больше лимита ОДО.
4. **Договоры во время приостановки** — дата заключения попадает в любой период приостановки.
4.1. **Превышен ВВ в период приостановки** — максимальный договор из пункта 4 больше лимита ВВ.
4.2. **Превышен ОДО во время приостановки** — остаток конкурентных договоров из пункта 4 больше лимита ОДО.
6. **Сверка ЕРЧ** — расхождение своего остатка ОДО с «Расчётом обязательств» реестра. Это ручная проверка, не автоматический критичный вывод.

Номер 5 в перечне не используется.

Статус права «приостановлено» или «прекращено» без договоров внутри дат периода остаётся критичным, но в счётчик пункта 4 не входит.

## Классификация риска

### КРИТИЧНО

- компания не найдена в реестре СРО по ИНН;
- право приостановлено (или прекращено);
- есть договоры, заключённые в период приостановки (в том числе превышение ВВ или ОДО только по этим договорам);
- максимальный договор превышает лимит ВВ;
- обязательства по конкурентным договорам превышают лимит ОДО;
- ОДО отсутствует / не указан, но есть договоры 44-ФЗ, 223-ФЗ или 615-ПП.

### РУЧНАЯ ПРОВЕРКА

- не указан способ закупки;
- не хватает колонок для точного расчёта;
- расхождение между расчётом по договорам и «Расчётом обязательств» в реестре (сверка ЕРЧ, пункт 6);
- неоднозначный ИНН / название;
- странный формат суммы;
- часть договоров без даты/стоимости.

### НОРМА

- компания найдена;
- право действует;
- max договор ≤ лимит ВВ;
- остаток конкурентных обязательств ≤ лимит ОДО (или конкурентных договоров нет);
- данные достаточно полные.

## Приоритет итогового статуса

Если есть хотя бы один критичный фактор → **КРИТИЧНО**.  
Иначе если есть факторы ручной проверки → **РУЧНАЯ ПРОВЕРКА**.  
Иначе → **НОРМА**.

## Порог «расхождения» остатков

Если абсолютная разница между расчётом по договорам и значением из реестра превышает **5%** от большего из двух значений (или фиксированно > 1 млн ₽ — применять оба условия через OR), помечать «ручная проверка».

Если в реестре есть **дата регистрации в реестре СРО**, в лимиты ВВ/ОДО и в сверку ЕРЧ входят договоры с датой заключения не раньше этой даты. Договор раньше регистрации в суммы не входит. В комментарии компании и в строке договора фиксируется: на дату заключения членства нет, с номером договора. Это основание на случай иска: обязательство возникло до членства. Договор без даты заключения остаётся в лимитах.

Если в реестре есть **дата расчёта обязательств**, для сверки ЕРЧ из уже отобранных договоров берётся остаток только по тем, у которых дата заключения не позже этой даты. Сошлось — пункт 6 не ставится, даже если полный текущий остаток с реестром расходится. Не сошлось — ручная проверка. Договоры без даты заключения не позволяют сделать срез по дате расчёта: тогда сравнивается остаток по договорам с даты регистрации. Неисполненный договор, заключённый в период членства и не позже даты расчёта, в совокупный размер входит.
