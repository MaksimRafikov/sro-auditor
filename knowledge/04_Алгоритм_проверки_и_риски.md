# Алгоритм проверки и классификация рисков

## Пошаговый алгоритм

1. Прочитать реестр членов СРО и реестр договоров.
2. Определить колонки по словарю (см. `03_Словарь_колонок_и_нормализация.md`).
3. Нормализовать ИНН в обоих файлах.
4. Сгруппировать договоры по ИНН.
5. Для каждого ИНН из договоров (и при необходимости из реестра):
   - найти карточку в реестре СРО;
   - проверить состояние права;
   - если есть даты приостановки — отобрать договоры, у которых дата заключения попадает в период приостановки;
   - найти max одного договора (по стоимости, принятой СРО к учёту);
   - сравнить max с лимитом ВВ;
   - отобрать конкурентные договоры;
   - посчитать остаток ОДО = сумма (принято − исполнено) по конкурентным;
   - сравнить остаток с лимитом ОДО;
   - сравнить свой расчёт с колонкой «Расчёт обязательств» реестра (если есть);
   - присвоить итоговый риск.
6. Сформировать сводку, список критичных, ручную проверку, детальную таблицу.

## Классификация риска

### КРИТИЧНО

- компания не найдена в реестре СРО по ИНН;
- право приостановлено (или прекращено);
- максимальный договор превышает лимит ВВ;
- обязательства по конкурентным договорам превышают лимит ОДО;
- ОДО отсутствует / не указан, но есть конкурентные договоры, требующие ОДО.

### РУЧНАЯ ПРОВЕРКА

- не указан способ закупки;
- не хватает колонок для точного расчёта;
- расхождение между расчётом по договорам и «Расчётом обязательств» в реестре;
- неоднозначный ИНН / название;
- странный формат суммы;
- часть договоров без даты/стоимости.

### НОРМА

- компания найдена;
- право действует;
- max договор ≤ лимит ВВ;
- остаток конкурентных обязательств ≤ лимит ОДО (или конкурентных договоров нет);
- данные достаточно полные.

## Приоритет итогового статуса

Если есть хотя бы один критичный фактор → **КРИТИЧНО**.  
Иначе если есть факторы ручной проверки → **РУЧНАЯ ПРОВЕРКА**.  
Иначе → **НОРМА**.

## Порог «расхождения» остатков

Если абсолютная разница между расчётом по договорам и значением из реестра превышает **5%** от большего из двух значений (или фиксированно > 1 млн ₽ — применять оба условия через OR), помечать «ручная проверка».
