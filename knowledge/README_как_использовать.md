# Как использовать комплект Knowledge для GPT «СРО-Аудитор»

## Что загружать в Knowledge GPT

Загрузите все файлы `01`–`07` из этой папки в раздел **Знания** кастомного GPT.

Не загружайте в Knowledge актуальные реестры членов СРО и выгрузки договоров — они устаревают. Их пользователь подгружает **в чат** при каждой проверке.

## Что вставить в Instructions

Скопируйте содержимое файла `06_Инструкция_GPT_СРО_Аудитор.md` в поле **Instructions**.

## Настройки возможностей

| Возможность | Статус |
|---|---|
| Интерпретатор кода / анализ данных | **Включить** |
| Поиск в сети | Можно включить |
| Холст | Выключить |
| Генерация изображений | Выключить |
| Actions | Пока не нужны |

## Стартовые команды

```text
Проверь реестр членов СРО и реестр договоров на превышение ВВ/ОДО.
```

```text
Найди компании с критичными рисками по СРО.
```

```text
Проверь одного подрядчика по ИНН и сумме нового договора.
```

```text
Сформируй Excel-отчёт по рискам СРО.
```

```text
Сравни расчёт обязательств из реестра СРО с расчётом по договорам.
```
